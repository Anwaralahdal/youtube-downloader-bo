# بوت تيليجرام لتحميل الفيديو — إعداد أولي

## الميزات
- تسجيل المستخدمين وإحصائيات للمالك.
- إذاعة رسالة نص/صورة/فيديو للمستخدمين الذين بدأوا البوت.
- زر مراسلة المالك.
- مفتاح تشغيل/إيقاف استقبال الرسائل العامة وتحويلها للمالك.
- خيارات تحميل فيديو/صوت عبر yt-dlp، مع مراعاة حقوق المحتوى وشروط المنصة.

## متطلبات مهمة
هذا مشروع أولي. تنزيل يوتيوب يعتمد على تغيّر الموقع وتوفر FFmpeg وسياسة الاستضافة. قد لا تعمل كل الجودات أو قد تتجاوز الملفات حد تيليجرام/الاستضافة. لا تستخدمه لتنزيل محتوى لا تملك حق تنزيله أو إذنًا به.

## المتغيرات السرية (Environment Variables)
- `BOT_TOKEN`: رمز البوت من BotFather.
- `OWNER_ID`: رقم Telegram ID الخاص بالمالك (رقم فقط).

لا تضع رمز البوت داخل الكود أو ترفعه إلى GitHub. أدخله في إعدادات Secrets/Environment Variables لدى الاستضافة.

## النشر
1. أنشئ مستودعًا جديدًا على GitHub باسم `telegram-video-bot`.
2. ارفع الملفات الموجودة في هذا المشروع إلى المستودع.
3. اربط المستودع بخدمة استضافة تدعم Python worker دائمًا.
4. أضف `BOT_TOKEN` و`OWNER_ID` كمتغيرات بيئة.
5. أمر التشغيل: `python bot.py`

## ملاحظات
- قاعدة SQLite قد لا تكون دائمة في بعض الاستضافات المجانية؛ استخدم قرصًا دائمًا أو قاعدة بيانات مُدارة إذا أردت الحفاظ على بيانات المستخدمين بعد إعادة النشر.
- الإذاعة ترسل إلى المستخدمين الذين ضغطوا Start فقط.
